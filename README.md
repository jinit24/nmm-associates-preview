# NMM Associates preview

A lightweight, responsive concept site for NM Malde & Associates. It is designed for early owner feedback before investing in the complete client and associate platform.

## Included

- Acquisition-focused homepage
- Expertise directory
- Income Tax service page
- Firm page
- Four-step request prototype
- Client Desk login and dashboard preview
- Associate operations preview

This is a static prototype. Forms do not transmit or store information, and all names/data in authenticated views are fictional.

## Run locally

```sh
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
